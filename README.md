# 画中界 / Painted Realm

团队最终整合版的独立网页发布副本。游戏入口为 `index.html`。

## 在线游玩

https://typosprovidence-netizen.github.io/painted-realm/

推荐使用桌面 Chrome。WASD 移动，Space 二段跳，J 攻击，U 破军，R 奥义，K 前冲；靠近背墙画壁后按 Q 入画，画中按 Q 出画，靠近界门按 E 通过。

Three.js、字体及程序化美术资源均已内置，不依赖外部 CDN，无需安装或构建。

## 版本来源

源自 2026-10-25 交付的“画中界_团队最终整合版”，基线 HUAZHONGJIE-B0.1，视觉 v3.1。10 个 HTML/JS/CSS 运行文件原样发布，未改变玩法或数值。

内嵌的 Three.js 与字体保留原有许可。手机、Safari、Firefox 和长时间性能尚未验收。
